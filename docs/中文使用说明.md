# 勋章灰度图生成器：中文使用说明

本仓库当前交付的是一个可在 Windows 本地运行的桌面软件，不是一张示例图片或一组工作文件。

当前版本只完成并验收第一阶段：

> 单张图片 → 可编辑的高精度灰度高度图

第二阶段“已批准灰度图 → 完整3D模型”保留为后续流程。灰度图没有通过复核前，不把3D预览当作完成结果。

## 打开软件

### 直接使用 Windows 程序

解压 GitHub Actions 生成的 Windows 压缩包，双击：

```text
BadgeReliefMaker.exe
```

双击后默认打开中文简化界面“勋章灰度图生成器”。

### 从源码运行

```powershell
python -m pip install -e ".[gui]"
python -m badge_relief_maker.app --gui
```

## 界面工作流

主界面只保留四个常用动作：

1. **导入图片**：支持实物照片、扫描图、线稿和草图。
2. **生成／刷新灰度图**：自动判断连续色调照片或黑白线稿，并生成区域图与灰度预览。
3. **导出高精度灰度图**：输出16位PNG、32位浮点TIFF及配套蒙版。
4. **打开导出目录**：直接查看正式文件。

“第二阶段：由批准灰度图生成3D”在当前界面中明确禁用，避免在灰度图尚未完成时混淆验收目标。

## 区域修正

中间的“区域与边界”预览可以直接点击。区域操作合并为一个下拉框：

- 查看区域；
- 挖空／设为背景；
- 设为承载面；
- 抬高为前景构件；
- 压低为凹陷／阴影。

所有修正按顺序累积保存。新一轮生成不会静默恢复已经确认的孔洞。只有“撤销最后一次区域修改”或“清除全部人工修正”会删除已有修正。

## 输出精度

软件提供三档正式输出：

- 标准：长边4096像素；
- 高精：长边8192像素；
- 极致：长边12288像素。

正式导出文件包括：

```text
height_master_16bit.png
height_master_32bit.tiff
height_master_preview.png
linework_mask.png
solid_mask.png
void_mask.png
source_aligned.png
height_master_manifest.json
```

其中：

- 16位PNG和32位TIFF是可继续编辑的灰度高度主图；
- `linework_mask.png`用于单独修改细线、刻纹和文字；
- `solid_mask.png`表示实体范围；
- `void_mask.png`表示累计确认的真实空隙；
- 8位预览只用于屏幕查看，不能替代16位／32位文件验收。

## 项目保存

导入图片后，软件会在原图旁自动创建一个带时间戳的项目目录，并保存 `.medalproj` 项目文件。关闭软件时会自动保存。可以通过“文件 → 打开已有项目”继续上次工作。

## 当前限制

低分辨率照片或线稿中不存在的雕塑信息，无法通过单纯放大真实恢复。软件会尽量分离大体块高度、精细线稿、实体范围和孔洞范围，并把不确定部分保留为可编辑内容，而不是用看似立体的渲染图掩盖错误。
