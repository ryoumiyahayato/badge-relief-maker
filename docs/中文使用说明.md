# 确定性灰度浮雕：最短使用说明

## 最短流程

```text
导入图片
→ 选择实体模式
→ 修正并确认实体蒙版
→ 选择高度模式
→ 修正并确认高度主图
→ 设置毫米尺寸
→ 生成网格
→ 导出
```

## 先分清两个东西

`solid_mask.png` 只回答“哪里有材料”：

```text
白色 = 有实体
黑色 = 没有实体
```

`height_master_16bit.png` 或 `height_master_32bit.tiff` 只回答“实体内部哪里高、哪里低”：

```text
0.0 = 最低表面
1.0 = 最高表面
```

白色可能是背景，也可能是白色底板，所以软件不会再把“白色”自动等同于“高”或“没有材料”。必须先确认实体范围，再选择高度解释。

## 第一步：实体

选择：

- **整个底板**：长方形铭牌、圆形奖牌或完整底板全部保留。
- **自动去背景**：优先透明通道，也可点击背景采样点，或选择亮背景/暗背景。结果只是初稿。
- **自定义实体范围**：增加、删除、填充封闭区域、删除连通组件、矩形和多边形选择，并可撤销/重做。

检查无误后点击“确认并锁定实体蒙版”。后续高度计算不会再改变实体范围。需要修改时，必须主动点击“返回修改实体”，这会同时取消高度确认。

## 第二步：高度

必须明确选择：

- 亮色凸起；
- 暗色凸起；
- 线条凹刻；
- 线条凸起；
- 固定高度。

亮色/暗色模式默认只统计实体内部像素，使用 2% 和 98% 百分位，减少少量高光、阴影和噪点的影响。可以调整最低点、最高点、中间调、反转并重置。

线稿模式先建立平面，黑线或亮线只按指定毫米数凹下或抬高，不会自动拉满整个浮雕高度。

高度画笔支持最低、低、中、高、最高、局部抬高、局部压低和局部平滑，并可使用圆形、矩形和多边形区域。所有修改按固定顺序保存，后续自动刷新不会跳过或偷偷覆盖已保存的人工操作。

检查无误后点击“确认并锁定高度主图”。

## 第三步：输出

设置：

```text
宽度 mm
高度 mm
基础厚度 mm
浮雕高度 mm
希望保留的最小特征 mm
质量：草稿 / 标准 / 精细
格式：OBJ / STL / GLB
```

默认使用规则共享顶点网格。报告会写出实际网格间距，而不是只给出“多少万个三角形”。希望保留的最小特征最好至少覆盖约 3 个采样单元，例如 0.3 mm 特征建议约 0.1 mm 网格间距。

## 正式文件

```text
source_aligned.png
solid_mask.png
height_master_16bit.png
height_master_32bit.tiff
height_master_preview.png
mesh_preview.png
project.json
output.obj / output.stl / output.glb
build_report.json
```

8 位 `height_master_preview.png` 只用于屏幕查看，不能作为正式网格输入。

## 真实照片必须注意

真实照片里的亮暗包含高光、阴影、材料颜色和反射。软件可以生成亮度映射草稿，但这不是从一张照片恢复出的真实几何，必须人工确认和修改。不要把自动预览当成精确三维重建。

## 高级功能

语义区域、贝塞尔轮廓、自适应网格和双面融合被放在“高级功能”入口。它们不影响默认批准主图，也不会在后台修改已经确认的 `solid_mask` 或 `height_master`。基础路径不依赖 SciPy；高级功能缺少依赖时，仍可使用规则网格完成基础导出。

## 外部验收

自动拓扑检查不能代替 Blender、切片器、CAM 或实体制造测试。正式制造前仍应在目标软件中检查尺寸、法线、闭合性、最小厚度和实际工艺限制。
